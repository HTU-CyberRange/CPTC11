# CPTC 11 Global Finals: Team 4

Working data and final report for Team 4 (Al Hussein Technical University, HTU) at the
Collegiate Penetration Testing Competition (CPTC) 11 Global Finals.

The engagement was a Q1 penetration re-test for the fictional client All Ports Tours
(`allports.local`), a maritime and cruise operator. Testing ran on 9 and 10 January 2026
against the internal network `10.0.1.0/24` using a grey box, assumed breach approach.

The assessment identified 4 Critical, 5 High, 14 Medium, 7 Low, and 9 Informational
findings. The highest impact issues were remote code execution and secret theft through
the Penny AI assistant, default and weak credentials on maritime control systems, and
disabled SMB signing on the Windows workstations.
