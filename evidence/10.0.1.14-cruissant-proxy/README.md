# 10.0.1.14 - CruissantServer (Reverse Proxy)

Production reverse proxy that fronts other in scope web services. Only light enumeration
was performed against this host directly, since most of its value is as a route to the
services behind it. No standalone finding was raised for the proxy itself.

There is no separate evidence directory for this host. Relevant traffic and findings are
recorded with the backend services under the other host directories and in the report.
